# Patrick — Landing pessoal (Vite + React + TypeScript)

Landing page moderna e responsiva para o corretor Patrick. Usa TailwindCSS e Framer Motion para animações sutis.

Início rápido

Instale as dependências:

```bash
npm install
```

Execute o servidor de desenvolvimento:

```bash
npm run dev
```

Build para produção:

```bash
npm run build
```

Pré-visualizar o build em produção:

```bash
npm run preview
```

Deployment

- Faça deploy da pasta `dist` em qualquer serviço de hospedagem estática (Vercel, GitHub Pages, Netlify).
